میرا مارکیٹ پلیس — Demo

یہ ایک marketplace prototype ہے:
- Sellers پروڈکٹ شامل کر سکتے ہیں
- Customer پروڈکٹس دیکھ سکتا ہے
- Demo order
- 5% مثال والا commission
- Wallet
- Withdrawal account field
- Withdrawal request

اہم: یہ صرف frontend/demo ہے۔ حقیقی GSK/Easypaisa/JazzCash یا کسی بھی payment account سے رقم بھیجنے/نکالنے کے لیے backend، database، merchant account/API اور provider کی منظوری درکار ہوگی۔ کسی دوسرے marketplace کا content بغیر اجازت copy نہ کریں۔
